学期：2026 秋 · 参考：周民强《实变函数论》

本书记录《实变函数》课程的学习笔记，以周民强《实变函数论》为参考，用 LaTeX（XeLaTeX + PKU-ElegantBook 模板）排版，共六章：第一章实分析研究动机与集合论（Riemann 积分的局限性、基本集合论、集合的基数、常用集合簇、Cantor 集与 Cantor 函数、Baire 纲集、连续延拓）；第二章 Lebesgue 测度（测度动机、外测度与 Carathéodory 条件、测度的基本性质、测度的正则性、正测度集的性质与 Steinhaus 定理、Brunn–Minkowski 不等式、Vitali 不可测集）；第三章可测函数及其性质（连续映射与可测映射、可测函数收敛定理（Lebesgue / Egoroff / Riesz）、可测函数与连续函数的关系（Lusin）、Littlewood 三原则、可测函数的复合）；第四章 Lebesgue 积分（非负可测函数的积分与 MCT / Fatou、广义实值可测函数积分与 DCT、DCT 的若干讨论、L¹ 空间的若干讨论、Riemann 积分与 Lebesgue 积分的关系、Fubini / Tonelli 定理、卷积）；第五章微分与不定积分（Vitali 覆盖与单调函数可微性、有界变差函数与 Jordan 分解、Lebesgue 微分定理与 Hardy–Littlewood 极大函数、微积分基本定理与绝对连续函数）；第六章 Lp 空间（Lp 空间定义与 Hölder / Minkowski 不等式、Lp 空间的度量结构（完备性、可分性、对偶表示）、恒同逼近与磨光）。每小节一页，点进任意一页后左侧栏会列出全书章节与当前章的小节，页底有「上一节 / 下一节」便于连续翻阅；定理、定义等数学环境带衬底彩盒，TikZ 插图已嵌入正文。本笔记另有 LaTeX 排版的 PDF 打印版（LaTeX 源码包，含模板与插图，XeLaTeX 编译）。
