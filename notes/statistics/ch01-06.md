### 1.6 密度函数与质量函数（Density and Mass Functions）

与随机变量 $$X$$ 及其 cdf $$F_X$$ 相联系的还有另一个函数，称为概率密度函数（pdf）或概率质量函数（pmf）。pdf 与 pmf 分别对应连续情形与离散情形；二者都涉及随机变量的“点概率”。

> **定义 1.6.1（概率质量函数）**
>
> 离散随机变量 $$X$$ 的***概率质量函数***（probability mass function，简称 pmf）定义为
>
> $$
f_X(x) = P(X = x) \qquad \text{对一切 } x.
$$

> **例 1.6.2（几何概率）**
>
> 对例 1.5.4 的几何分布，pmf 为
>
> $$
f_X(x) = P(X = x) = \begin{cases}
(1-p)^{x-1} p & \text{若 } x = 1, 2, \ldots,\\
0 & \text{其他}.
\end{cases}
$$
>
> 回顾 $$P(X = x)$$（等价地 $$f_X(x)$$）是 cdf 在 $$x$$ 处跳跃的大小。现在可以利用 pmf 计算概率了：既然能度量单点的概率，只需对相应事件中的所有点求和。故对正整数 $$a$$、$$b$$，$$a \leq b$$，有
>
> $$
P(a \leq X \leq b) = \sum_{k=a}^{b} f_X(k) = \sum_{k=a}^{b} (1-p)^{k-1} p.
$$
>
> 作为其特例，
>
> $$
P(X \leq b) = \sum_{k=1}^{b} f_X(k) = F_X(b). \tag{1.6.1}
$$

一个被广泛接受、本书也将采用的约定是：cdf 用大写字母，相应的 pmf 或 pdf 用对应的小写字母。

连续情形下 pdf 的定义要更小心些。若天真地想对连续随机变量计算 $$P(X = x)$$，会得到：由于对任意 $$\varepsilon > 0$$ 有 $$\lbrace X = x \rbrace \subset \lbrace x - \varepsilon < X \leq x \rbrace$$，由定理 1.2.9(c) 得

$$
P(X = x) \leq P(x - \varepsilon < X \leq x) = F_X(x) - F_X(x - \varepsilon),
$$

故

$$
0 \leq P(X = x) \leq \lim_{\varepsilon \downarrow 0} \bigl[ F_X(x) - F_X(x - \varepsilon) \bigr] = 0,
$$

最后一步由 $$F_X$$ 的连续性。不过，只要理解 pdf 的目的，它的定义就会清楚了。

由例 1.6.2 可见，pmf 提供“点概率”。离散情形可对 pmf 的值求和得到 cdf（如 (1.6.1)）；连续情形的类似操作是把求和换成积分：

$$
P(X \leq x) = F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt.
$$

由微积分基本定理，若 $$f_X(x)$$ 连续，则进一步有

$$
\frac{d}{dx} F_X(x) = f_X(x). \tag{1.6.2}
$$

注意与离散情形的类比几乎完全一致：我们“加总”“点概率”$$f_X(x)$$ 以得到区间概率。

> **定义 1.6.3（概率密度函数）**
>
> 连续随机变量 $$X$$ 的***概率密度函数***（probability density function，简称 pdf）$$f_X(x)$$ 是满足
>
> $$
F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt \qquad \text{对一切 } x \tag{1.6.3}
$$
>
> 的函数。

> **记号**：“$$X$$ 具有由 $$F_X(x)$$ 给出的分布”在符号上缩写为“$$X \sim F_X(x)$$”，符号“$$\sim$$”读作“服从（的分布为）”。类似地可写 $$X \sim f_X(x)$$；若 $$X$$ 与 $$Y$$ 同分布，还可写 $$X \sim Y$$。

连续情形下区间概率的写法可以比较随意：既然连续随机变量满足 $$P(X = x) = 0$$，便有

$$
P(a < X < b) = P(a < X \leq b) = P(a \leq X < b) = P(a \leq X \leq b).
$$

显然 pdf（或 pmf）与 cdf 含有同样的信息。既然如此，两个都可以用来解题，应当选择较简便的那一个。

> **例 1.6.4（逻辑斯蒂概率）**
>
> 对例 1.5.5 的逻辑斯蒂分布，
>
> $$
F_X(x) = \frac{1}{1 + e^{-x}},
$$
>
> 因而
>
> $$
f_X(x) = \frac{d}{dx} F_X(x) = \frac{e^{-x}}{(1 + e^{-x})^2}.
$$
>
> 曲线 $$f_X(x)$$ 下的面积给出区间概率（见图 1.6.1）：
>
> $$
\begin{aligned}
P(a < X < b) &= F_X(b) - F_X(a)\\
&= \int_{-\infty}^{b} f_X(x)\, dx - \int_{-\infty}^{a} f_X(x)\, dx\\
&= \int_{a}^{b} f_X(x)\, dx.
\end{aligned}
$$

pdf（或 pmf）其实只有两条要求，它们都是定义的直接推论。

> **定理 1.6.5（pdf/pmf 的刻画）**
>
> 函数 $$f_X(x)$$ 是随机变量 $$X$$ 的 pdf（或 pmf）当且仅当
>
> - a. 对一切 $$x$$，$$f_X(x) \geq 0$$；
>
> - b. $$\sum_{x} f_X(x) = 1$$（pmf 情形），或 $$\int_{-\infty}^{\infty} f_X(x)\, dx = 1$$（pdf 情形）。
>
>
> **证明**　若 $$f_X(x)$$ 是 pdf（或 pmf），则两条性质由定义直接得到。特别地，对 pdf，利用 (1.6.3) 与定理 1.5.3 有
>
> $$
1 = \lim_{x \to \infty} F_X(x) = \int_{-\infty}^{\infty} f_X(t)\, dt.
$$
>
> 逆命题同样容易证明：有了 $$f_X(x)$$ 即可定义 $$F_X(x)$$，再援引定理 1.5.3。 ∎

从纯数学角度看，任何非负且具有有限正积分（或和）的函数都可以改造成 pdf 或 pmf。例如，若 $$h(x)$$ 是非负函数，在集合 $$A$$ 上取正值、其余处为 0，且

$$
\int_{\lbrace x \in A \rbrace} h(x)\, dx = K < \infty
$$

对某常数 $$K > 0$$ 成立，则 $$f_X(x) = h(x)/K$$ 就是取值于 $$A$$ 的随机变量 $$X$$ 的 pdf。

实际上，关系式 (1.6.3) 并非总是成立，因为 $$F_X(x)$$ 可以连续但不可微。甚至存在连续随机变量，对任何 $$f_X(x)$$ 积分关系都不存在。这些是相当病态的情形，我们将忽略之。因此本书假定 (1.6.3) 对任何连续随机变量成立。在更高级的教科书中（如 Billingsley 1995, Section 31），若 (1.6.3) 成立则称该随机变量***绝对连续***（absolutely continuous）。
