### 2.4 禀赋模型：数值例子（自给自足）

> **禀赋模型设定**（第 19–21 页）
>
> - 两种商品：小麦（wheat, $W$）与布（cloth, $C$）；**无生产**（手写 "No production"）；
> - 禀赋：$Q_w = 100$，$Q_c = 200$ $\Rightarrow$ PPF 退化为一个**点** $(100,200)$；
> - 消费 $C_w, C_C$，价格 $P_w, P_C$；自给自足下 $C_w = Q_w,\ C_c = Q_c$；
> - **Cobb–Douglas 偏好（荧光高亮）**：$U = C_w^{0.2} C_C^{0.8}$。

![ch02_fig_05](fig/ch02_fig_05.png)

> **无差异曲线与全微分**（第 20 页手写）：$U(C_w, C_C) = \bar U$ 全微分得 $MU_w\, dC_w = -MU_C\, dC_C \Rightarrow \frac{dC_C}{dC_w} = -\frac{MU_w}{MU_C}$——无差异曲线斜率 = 边际效用之比的负值。

> **自给自足均衡的"三步解法"**（第 21 页手写，"Dealer"）
>
> 收入来自把全部禀赋卖给"交易商"（手写 "Dealer"），预算平衡要求 $I = P_w C_w + P_c C_c$。三步：
>
> 1. **把全部产品卖给 Dealer**：$I = P_w Q_w + P_c Q_c$；
> 2. **从 Dealer 处购买**：$\max_{C_w,C_C} U = C_w^{0.2}C_C^{0.8}$ s.t. $P_w C_w + P_c C_c = I$；
> 3. **自给自足均衡条件**：$C_w = Q_w$，$C_C = Q_C$。

![ch02_fig_06](fig/ch02_fig_06.png)

**最优预算线：经过禀赋点（PPF），并与无差异曲线相切（第 22 页）**——手写"相切"条件：IC 斜率 $-\frac{MU_1}{MU_2} = -\frac{P_1}{P_2}$（预算线斜率），即 $MU_1/P_1 = MU_2/P_2$。

**一阶条件与 C–D 支出法则**（第 23 页）：$\frac{MU_C}{P_c} = \frac{MU_w}{P_w}$ $\Rightarrow$ $P_w C_w = 0.2 I$，$P_c C_c = 0.8 I$（手写联立 $P_w C_w = 0.2I$、$P_c C_c = 0.8I$、$P_w Q_w + P_c Q_C = I$，并利用 $Q_w = C_w,\ Q_C = C_C$）。

> **PPT 红字提示（第 23 页）**：对 C–D 效用 $U = \prod_{g=1}^G C_g^{\alpha_g}$，永远有
> $$C_g P_g = \frac{\alpha_g}{\sum_{i=1}^G \alpha_i}\, I$$
> （荧光高亮）：**商品 $g$ 上的支出与 $\alpha_g$ 成正比**。

![ch02_fig_07](fig/ch02_fig_07.png)

**解自给自足价格**（第 25–27 页）：解得 $P_w = 0.2I/100$，$P_c = 0.8I/200$，$I = 100 P_w + 200 P_c$。手写指出：**2 个独立方程、3 个未知数**——只能解出相对价格：

$$\frac{P_w}{P_C} = \frac{0.2/100}{0.8/200} = \frac{1}{2}$$

市场通过**相对价格的调整**（荧光高亮）达到均衡，而不是（多个）绝对价格！所有价格与收入同乘任意正数仍是均衡——回忆**瓦尔拉斯定理**。2 个市场只有 1 个"有效"价格：**把另一种价格当作计价物（numeraire，荧光高亮）**（如令 $P_c = 1$）。板书：令 $P_c = 1$ 解得 $P_w = 1/2$，$P_c = 1$，$I = 250$——这解释了为什么贸易理论中通常使用**相对价格**。
