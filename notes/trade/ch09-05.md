### 9.5 外包模型的形式化：任务连续统

> **生产侧**（第 42–43 页）：生产一单位最终品需要许多任务 "s"（高亮 "skill intensity" 手写），沿轴从 $s = 0$ 排到 $s = 1$——"s 的连续统（**continuum**，粉底高亮）"；每项任务 "s" 需要 "s" 单位高技能工人与 "1−s" 单位低技能工人（手写：H：$s\, w_H + (1-s)\, w_L$；F：$T w_H^*$、$T w_L^*$）。

**任务成本与最终品价格**（第 43 页）：任务 "s" 的成本（粉底高亮）：**$C(s) = s W_H + (1-s) W_L$**；无外包时的**最终品价格**（粉底高亮）：

$$P_F = \int_{s=0}^{s=1} C(s)\, ds = \int_{s=0}^{s=1}\left[ s W_H + (1-s) W_L \right] ds$$

**外包决策**（第 44–46 页）：任务 "s" 在 Home 的成本 $C(s)$；外包的成本 $C^*(s) = s W_H^* + (1-s) W_L^*$；**若 $T \cdot C^*(s) < C(s)$ 则外包**。

- **情形 a**：若 $T w_L^* < w_L$ 且 $T w_H^* < w_H$（手写 $s = 0$、$s = 1$ 两端），则对所有 "s" 有 $T C^*(s) < C(s)$——**所有任务都被外包**（红字）；
- **情形 d**：若 $T w_L^* > w_L$ 且 $T w_H^* > w_H$，则对所有 "s" 有 $T C^*(s) > C(s)$——**没有任务被外包**（红字）；
- **情形 b**（板书推导）：若 $T w_L^* < w_L$ 且 $T w_H^* > w_H$：由 $sTW_H^* + (1-s)TW_L^* < sW_H + (1-s)W_L$ 整理（手写逐步，并标注 "save cost by using cheap L" 与 "waste cost by using expensive H"）：

$$s^* = \frac{W_L - T W_L^*}{(W_H - T W_H^*) + (W_L - T W_L^*)}$$

  **解：低于阈值 $s^*$ 的任务被外包**——**低技能任务（$s < s^*$）外包；高技能任务（$s > s^*$）留在国内**。

**图形说明**（第 47 页）：外包成本曲线 $TC^*(s) = sTW_H^* + (1-s)TW_L^*$（黄）与国内成本线 $C(s) = sW_H + (1-s)W_L$（蓝）相交于 $s^*$：左侧 **offshore**（手写）、右侧 **stay**（手写）。
