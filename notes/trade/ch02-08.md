### 2.8 本讲总结：通用结论与方法

1. **建模语法**：模型 = 设定（谁在决策、选择集、交易条件）+ 目标与约束 + 均衡概念；先分清内生/外生变量（厂商例子：$L_i, K_i, Q_i, P_i$ 内生；$w_i, r_i, F, P(Q_i)$ 外生）。
2. **古典贸易模型共同设定**：≥2 国（另一国可记为 ROW）、≥2 种商品（一种商品无法平衡预算）；供给面 = 禀赋 + 技术 → PPF + 完全竞争（MC=P，w=MRPL，r=MRPK）；需求面 = 同质位似偏好下的代表性主体（IC + 预算约束）。
3. **关键均衡条件**：开放贸易后**相对价格均等化**（无套利）；套利是价格均等化的微观机制（低买高卖的"迂回贸易"）；相对价格 = 市场交换比率 = 机会成本，对汇率中性。
4. **C–D 效用的工作马**：$U = \prod_g C_g^{\alpha_g}$ $\Rightarrow$ $C_g P_g = \frac{\alpha_g}{\sum_i \alpha_i} I$——支出份额等于幂次；这是所有解析求解的引擎（板书有完整证明）。
5. **价格只定相对值**：$N$ 个市场只有 $N-1$ 个独立价格（瓦尔拉斯定理）；把一种商品记为 numeraire；均衡由相对价格调整实现。
6. **禀赋模型三段论**：禀赋差异 → 自给自足相对价格差异 → 贸易模式（出口相对丰裕品）；世界均衡价格介于两国自给自足价格之间（出口国自给价 ≤ 世界价 ≤ 进口国自给价）。
7. **贸易必然平衡**：预算约束 $\Rightarrow$ $\sum_g EV_g = 0$（无顺差逆差）；**两国都得益**（显示偏好：原消费束仍可负担 + 选择集扩大）。
8. **一般化核心公式**：$EV_g^i = \beta_g I \left(\frac{Q_g^i}{Q_g^w} - \frac{I^i}{I}\right)$——出口该商品 ⟺ 该商品的世界禀赋份额 > 世界收入份额；石油贸易数据验证良好。
