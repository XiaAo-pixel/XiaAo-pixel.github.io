### 2.5 两国贸易均衡与世界价格

> **两国设定**（第 29–31 页）两国偏好相同（$U = C_w^{0.2} C_C^{0.8}$）；Home 禀赋 $Q_w^H = 100$，$Q_C^H = 200$；Foreign 禀赋 $Q_w^{Fa} = 200$，$Q_C^{Fa} = 200$。**F 相对更丰裕于小麦（wheat）**（红字）。
>
> **自给自足价格**：$P_w = 0.2 I/Q_w$，$P_c = 0.8 I/Q_c$（以布为计价物 $P_c = 1$）：
>
> - H 国：$P_w^{Ha} = 0.5$，$P_c^{Ha} = 1$（手写标注 autarky）；
> - F 国：$P_w^{Fa} = 0.25$，$P_c^{Fa} = 1$；手写验算 $\left(\frac{P_w}{P_c}\right)^{Fa} = \frac{0.2I/200}{0.8I/200} = \frac{1}{4}$。
>
> 小麦在 **H** 相对更贵——自给自足下 **F** 出口小麦到 **H**；反之 **H** 出口布到 **F**。**贸易的原因：两国禀赋的差异**（红笔下划线）。

> **贸易模式命题**（第 31 页，荧光高亮）：**在某种商品的禀赋上（相对）更丰裕的国家，把该商品出口给在该商品禀赋上相对更稀缺的国家。**

**世界贸易均衡**（第 32–34 页）：把世界当作一个更大的经济体：世界偏好仍为 $U = C_w^{0.2}C_C^{0.8}$（$C_w = C_w^H + C_w^F$ 等）；世界总禀赋 $Q_w = Q_w^H + Q_w^F = 300$，$Q_C = Q_C^H + Q_C^F = 400$。两国价格必须均等（无套利）；仍需国际计价物，继续令 $P_c = 1$（现实中通常由美元扮演）。由 C–D 支出法则（世界层面）：

$$P_w = \frac{0.2I}{300},\quad P_c = \frac{0.8I}{400} \;\Longrightarrow\; \frac{P_w}{P_c} = \frac{1}{3}$$

手写不等式（关键结论）：

$$\underbrace{\left(\tfrac{P_w}{P_c}\right)^{\text{autarky, 出口国}}}_{=1/4} \;\le\; \underbrace{\left(\tfrac{P_w}{P_c}\right)^{\text{trade}}}_{=1/3} \;\le\; \underbrace{\left(\tfrac{P_w}{P_c}\right)^{\text{autarky, 进口国}}}_{=1/2}$$

> **一般化命题**（第 34 页，荧光高亮）：**均衡中的世界价格总是（弱地）介于两国的自给自足相对价格之间。**

**Home 的贸易均衡**（第 35–39 页）：贸易下新预算线 $P_w C_w^H + P_c C_c^H = P_w Q_w^H + P_c Q_c^H$（板书 $I = 200P_c + 100P_w$）。贸易后小麦相对更便宜；**预算线扩张表明福利改善**（手写 "revealed preference"（显示偏好）指向该句，并手写两条理由：**① 效用水平提高；② 选择范围扩张（原来的消费仍可保留）**）。

> **"Gain from Trade"**（第 36 页，荧光高亮）：贸易得益源于小麦的稀缺通过与在该商品上更丰裕的伙伴贸易得到补偿。贸易后消费点从 PPF 上的禀赋点移到更高无差异曲线上（出口布、进口小麦）。

![ch02_fig_08](fig/ch02_fig_08.png)

**求解消费与贸易流**（第 37–38 页）：均衡时 $P_w = 1/3$，$P_c = 1$。收入 $I = \frac{1}{3}\times 100 + 200 = \frac{700}{3}$（板书验算）。由 $P_w = 0.2I/C_w^H$：

$$\frac{1}{3} = 0.2 \times \frac{700/3}{C_w^H} \;\Longrightarrow\; C_w^H = 140,\qquad C_C^H = 186.7$$

于是布的出口 $EX_c = Q_c^H - C_c^H = 13.3$；小麦的进口 $IM_w = C_w^H - Q_w^H = 40$。

![ch02_fig_09](fig/ch02_fig_09.png)

> **贸易平衡（Trade Balance，第 39 页）**：出口价值 $EV_c = P_c(Q_c^H - C_c^H) = 1 \times 13.3 = 13.3$；进口价值 $IV_w = P_w(C_w^H - Q_w^H) = \frac{1}{3}\times 40 = 13.3$（板书验算）。两者相抵：**贸易平衡**。手写推导：预算约束移项 $\underbrace{P_c(Q_c - C_c)}_{EV_c} - \underbrace{P_w(C_w - Q_w)}_{IV_w} = 0$。

> **禀赋模型小结**（第 40 页原文红字）
>
> - 各国**自给自足相对价格**不同，原因是**相对禀赋丰裕度**不同；
> - **贸易模式**：出口自给自足下相对更便宜的商品（即在禀赋上相对更丰裕），进口禀赋相对更稀缺的商品；
> - **贸易为什么能发生？贸易商靠套利赚钱！**
> - **国家为什么允许贸易？两国福利都从贸易中得益！**
